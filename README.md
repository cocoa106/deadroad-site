# deadroad.co.kr

DEAD ROAD(모바일 생존 시뮬레이션 게임) 안내 사이트. GitHub Pages 가 `main` 브랜치 루트를 `https://deadroad.co.kr` 로 낸다.

| 파일 | 쓰임 |
|---|---|
| `index.html` | 안내 페이지(스토어 등록정보 문구·그림 기준) |
| `app-ads.txt` | 광고 판매자 선언(AdMob). 광고 네트워크를 더하면 줄을 추가한다 |
| `CNAME` | GitHub Pages 사용자 도메인 |
| `.nojekyll` | 파일을 그대로 낸다(Jekyll 처리 없음) |
